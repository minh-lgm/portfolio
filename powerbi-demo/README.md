# Retail Sales Demo (Power BI, synthetic data)

Portfolio report. All data is generated by `data/generate_data.py`; no real company, customer or employee appears.

- Open `RetailSalesDemo.pbip` in Power BI Desktop. On the first open click **Refresh** once (there is no saved data cache), then dismiss any auto-recovery notice.
- The Sales table reads `data/sales_orders.csv` through an absolute path set in `RetailSalesDemo.SemanticModel/definition/tables/Sales.tmdl`. If you move the folder, update that path.
- Pages: 1 Sales Overview, 2 Product & Rep Performance. Measures live in the `_Measures` table (revenue, profit, margin, orders, prior-year and YoY variants via `SAMEPERIODLASTYEAR`).
- Rebuild the PBIR from scratch: `node build/build_report.js`; rebuild the model: `python build/write_model.py`; validate: `powerbi-report-author validate`.
- Screenshots used on the portfolio page are in `screenshots/` (downscaled copies in `../img/pbi-*.png`).
